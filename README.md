# Express Cats API

A small Express REST API that returns cat data as JSON and serves a local image.

## Run

```sh
npm install
npm run dev
```

Open `http://localhost:3000/api/v1/cats` for the cat JSON or
`http://localhost:3000/public/cat.svg` for the locally served image.

Use `npm start` to run the server with Node.js without nodemon.
